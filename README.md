# KalingaPH – HUMCOM 1 Final Project (SDG 4: Quality Education)

Mental health support for Filipino students, teachers, and families. Plain HTML5, CSS3, and basic JavaScript. No Bootstrap.

## Before you submit (do these)
1. **about.html**: replace `[Your Name]`, `[Section]`, and `you@example.com`.
2. **references.html**: add dates/retrieval dates to the APA entries as your instructor requires, then open every link.
3. **Re-check phone numbers** in `js/data.js` and `crisis.html` (they were taken from your Kalinga.html and not re-verified).
4. **Put it on GitHub** (push the *contents* of this folder, so `index.html` is at the top of the repo, not inside a subfolder):
   ```
   cd kalingaph
   git init
   git add .
   git commit -m "KalingaPH final project"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
   git push -u origin main
   ```
   Or on github.com use **Add file > Upload files** and drag in everything inside the folder (including the `css`, `js`, `images`, `videos` folders and the hidden `.nojekyll` file).
5. On GitHub: **Settings > Pages > Source: Deploy from a branch > main / (root) > Save**. After about a minute your site is at `https://YOUR-USERNAME.github.io/YOUR-REPO/`. Submit that link and the repository link.
